# Limitations

- **Public docs only.** No access to internal policy, agent macros, or routing logic. Real support agents may have better information than what is publicly visible.
- **Small sample.** A limited number of issue families and articles per company. Findings are directional, not statistically representative.
- **No account-specific workflows.** Many real resolutions depend on authenticated state (order ID, account tier, region). This audit can flag account-dependence but not test it.
- **Snapshot in time.** KBs change frequently. The findings reflect the source state on the dates listed in `data/raw/support_kb_sources.csv`.
- **Exploratory audit.** This is a portfolio-grade artifact, not a peer-reviewed study. The scoring rubric is auditable but subjective.
- **English-only.** Localized content was not evaluated.
