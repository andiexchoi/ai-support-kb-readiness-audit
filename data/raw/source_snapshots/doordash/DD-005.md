# DD-005 — I accidentally placed a duplicate order

Company: DoorDash
URL: https://help.doordash.com/en-us/consumers/article/i-accidentally-placed-a-duplicate-order
Date accessed: 2026-06-05
Visible last updated date: Not visible

## Relevant issue families

- duplicate_or_unexpected_charge

## Source summary

Public help-center article addressing the scenario where a customer accidentally placed **two separate orders**, not a true duplicate charge for a single order. Directs the customer to cancel the duplicate through the standard in-app cancellation flow and refers to the standard cancellation refund rules (the same status-based rules as DD-004).

## Relevant policy language summary

- Refund eligibility for the duplicate order follows the standard cancellation rules: pre-confirmation full refund, confirmed-but-no-Dasher partial refund, Dasher-assigned no refund.
- Does **not** directly address duplicate authorization holds or true duplicate charges on a single order.

## User action required

- Cancel the duplicate order via Orders > Help > Cancel Order.
- Refund depends on order status at cancellation.

## Escalation path

- Routes to in-app cancellation flow and support.
