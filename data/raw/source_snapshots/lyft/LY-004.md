# LY-004 — Lost & found for riders

Company: Lyft
URL: https://help.lyft.com/hc/en-us/all/articles/115012922987-Lost-found-for-passengers
Date accessed: 2026-06-06
Visible last updated date: Not visible

## Relevant issue families

- lost_item

## Source summary

Rider-facing Lost & found guidance. Best path is to contact the driver directly via the in-app 'Find Lost Item' flow, which uses a masked phone number. Includes a lost-phone form for cases where the rider cannot reach the driver. References a 24-hour contact window after the ride. Mentions a return fee (commonly cited as $20) to compensate drivers for time and gas. Does not guarantee recovery and does not reimburse for lost items.

## Relevant policy language summary

- Recovery is not guaranteed.
- No reimbursement for lost items.
- Drivers may receive a return fee for returning items.
- 24-hour window referenced for driver contact.

## User action required

- Use 'Find Lost Item' in ride history to message or call the driver via masked phone.
- If you lost your phone, use the lost-phone form.

## Escalation path

- Masked-text driver contact.
- Lost-phone form.
- Lyft Help follow-up if driver unreachable.
