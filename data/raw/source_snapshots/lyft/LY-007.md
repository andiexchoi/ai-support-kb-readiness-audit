# LY-007 — Ride pricing and charges

Company: Lyft

Visible last updated date: Not visible

## Relevant issue families

## Source summary

Rider-facing pricing article. Explains why prices can change between upfront estimate and final charge: route or destination changes, added stops, traffic, tips, tolls, demand, and ride duration. Provides a dispute path via Ride history. Does not state explicit conditions under which Lyft will adjust the fare if the rider believes the upfront price was wrong.

## Relevant policy language summary

- Lists reasons for upfront/final price differences (route, destination, stops, traffic, tips, tolls, demand, duration).
- Does not commit to fare adjustments when the rider disputes the upfront price.

## User action required

- Review Ride history for the specific ride.
- If disputing a charge, follow the in-app dispute flow.

## Escalation path

- Routes to in-app dispute flow.
